# Nala — Illustrated Creative Portfolio

Static HTML/CSS/JS portfolio inspired by the supplied illustrated portfolio reference.

## Included
- `index.html`
- `style.css`
- `script.js`
- `assets/hero-art.svg`
- `assets/intro-art.svg`
- `assets/hobbies.svg`

The illustration assets are original SVGs created for this template. Project thumbnails use remote Unsplash image URLs. Replace those URLs with locally licensed project artwork for production.

## Run
Open `index.html` directly or use:
`python -m http.server 8000`

Then visit `http://localhost:8000`.
